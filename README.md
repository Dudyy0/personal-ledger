# 个人账本 Personal Ledger

个人账本是一款面向 macOS 的本地财务整理工具，用于整合支付宝与工商银行流水，并把自动分类、重复交易识别和人工复核集中到一个清晰的界面中。

应用默认离线运行。账单、分类规则、预算与数据库保存在你的 Mac 上，不会上传到服务器。

## 主要功能

- 导入支付宝 CSV；
- 导入工商银行 CSV、XLSX、XLS 和带文字层的 PDF；
- 自动识别重复导入、支付宝与银行卡重复扣款；
- 区分真实收支、退款、账户互转、借还款及其他资金流动；
- 使用预设规则自动分类，并把无法可靠判断的记录留在“待确认”；
- 支持人工修正分类并保存为本地规则；
- 查看月度收入、消费、结余、储蓄率、分类支出和预算；
- 导出月度 Excel、已确认账单和 iCost 导入文件；
- 创建和恢复本地数据库备份。

## 使用方法

1. 在“导入账单”中选择支付宝或工商银行导出的账单文件；
2. 点击“检查文件”，确认识别数量、时间范围及解析结果；
3. 点击“导入并分析”；
4. 在“待确认”中处理有歧义的交易；
5. 在“本月概览”和“流水明细”中查看结果；
6. 在“导出与备份”中生成报表或备份。

## 安装

当前版本适用于 Apple 芯片 Mac。

1. 从 [Releases](https://github.com/Dudyy0/personal-ledger/releases) 下载 `PersonalLedger-macOS-arm64.zip`；
2. 解压后，将“个人账本.app”拖入“应用程序”文件夹；
3. 打开“个人账本”。

当前版本尚未使用 Apple Developer ID 签名和公证。如果 macOS 首次打开时进行拦截，可在“系统设置 → 隐私与安全性”中确认打开。

## 数据与隐私

应用数据默认保存在：

```text
~/Library/Application Support/PersonalLedger/
```

- 原始账单仅被读取，不会被修改或删除；
- 工行 PDF 密码只在本次检查期间保存在内存中；
- 应用不会主动联网或上传财务数据；
- 账本数据库、备份与导出文件可能包含敏感财务信息，请妥善保管；
- 建议开启 FileVault，并避免将未加密的备份或导出文件发送给他人。

## 当前限制

- 仅提供 Apple 芯片 macOS 版本；
- 扫描图片型 PDF 不能识别，需要使用银行导出的带文字层电子明细；
- 自动分类不能替代人工复核，待确认交易不会计入正式月度统计；
- iCost 模板不支持退款类型，因此 iCost 专用导出会跳过退款并提示数量。
